# SPM Works

Notes on SPM Works, the maker of the MONGDOL 87 and the SPM AL21W numpad
([testers/themrsung](../testers/themrsung.md)).

- [slow-file-downloads-from-spm-works-website](slow-file-downloads-from-spm-works-website/README.md):
  files from SPM Works' website download slowly. Expect it, don't retry in a loop, and hand the
  link to a human if `curl` fails.
- [al21w-factory-reset](al21w-factory-reset/README.md): the AL21W's keymap reset over VIA, and the
  hardware reset (hold Fn + 0 for about 3 seconds; a tap doesn't do it), with the factory keymap.
