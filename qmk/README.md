# QMK keycodes

- [japanese-keycodes-on-macos](japanese-keycodes-on-macos/README.md): which of QMK's Japanese and
  language keycodes macOS acts on (`KC_LNG1`, `KC_LNG2`, `KC_INT1`–`KC_INT3`) and which it drops
  (変換, 無変換, `KC_LNG3`–`KC_LNG5`).
- [lang-keycode-names](lang-keycode-names/README.md): `KC_HAEN`, `KC_HANJ` and `KC_KANA` are named
  for Korean and Windows keyboards, and arrive on a Mac as かな, 英数 and かな.
