# Configuration files

Ready-to-load configuration files for specific keyboards, one folder per keyboard and setup. Each
folder's README says which board, which firmware or tool it's for, how to load it, and the
assumptions it was built around.

Where [`layouts/`](../layouts/README.md) and [`layouts-windows-ko-kr/`](../layouts-windows-ko-kr/README.md)
describe a design for one platform each, a file here is what goes on the hardware, and may carry
more than one layout, for example one per side of a Mac / Windows switch.

| Folder | Keyboard | Platforms |
|---|---|---|
| [keychron-c2-pro-us-ansi-to-jis](keychron-c2-pro-us-ansi-to-jis/README.md) | Keychron C2 Pro (US ANSI, RGB), VIA | macOS and Windows, one per side of the switch |
| [hhkb-studio-jis](hhkb-studio-jis/README.md) | HHKB Studio JIS, HHKB Studio Keymap Tool | macOS: the golden layout, with Back / Forward on Fn2 + 英数 / かな; a one-handed option adds ⌘ shortcuts, app and tab switching on Fn2 |
