# VIA

- [any-key-rejects-layer-tap](any-key-rejects-layer-tap/README.md): VIA's Any key wouldn't take
  `LT(x,y)` for a Hansung keyboard; writing it over raw HID worked.
- [raw-hid-keymap-editing](raw-hid-keymap-editing/README.md): `viahid`, read and write a VIA
  keyboard's keymap from the command line on macOS, with a table of useful keycode values.
- [keycap-legend-language-and-jis](keycap-legend-language-and-jis/README.md): an ANSI board started
  working as JIS right after VIA's keycap legend language was set to Japanese (unconfirmed).
