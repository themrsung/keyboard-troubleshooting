# Keychron

- [nape-pro-usb-settings](nape-pro-usb-settings/README.md): the Nape Pro trackball's buttons, dial,
  DPI, ball orientation and gestures, read and written over USB without Keychron Launcher. VIA's
  raw-HID protocol plus Keychron's `a7` commands, taken from Launcher's own code.

The Keychron C2 Pro's layout is in [configfiles/keychron-c2-pro-us-ansi-to-jis](../configfiles/keychron-c2-pro-us-ansi-to-jis/README.md).
