# HHKB US on a Mac, rev2

Layouts for an HHKB US on macOS, built up from the board as
[measured](../hhkb/key-legends/hhkb-us.md) rather than from the earlier
[hhkb-pro-bt-us-to-jis](../layouts/hhkb-pro-bt-us-to-jis/README.md). They follow the macOS
[principles](../layouts/PRINCIPLES.md), with the HHKB Studio JIS
[golden layout](../layouts/hhkb-jis-golden/README.md) as the reference.

| Layout | Keyboard | How |
|---|---|---|
| [hhkb-us-mac-golden-rev2](hhkb-us-mac-golden-rev2/README.md) | HHKB Professional BT (US), Bluetooth | Karabiner-Elements, one rule |

The drawings come from the same renderer as the macOS ones
([layouts/render](../layouts/README.md#the-drawings)).
