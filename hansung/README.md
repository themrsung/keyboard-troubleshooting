# Hansung (한성컴퓨터)

- [mod-tap-rshift-bug](mod-tap-rshift-bug/README.md): mod-tap keys add right Shift and send the
  modifier and the tap key together on every press (firmware 5.9.2). Layer-tap is fine.
- [web-driver-internals](web-driver-internals/README.md): the web driver at app.superstore.co.kr is
  VIA's raw-HID protocol plus Hansung's commands; firmware version, keycode tables, UI limits.
- [via-definition-magnetox-xf](via-definition-magnetox-xf/README.md): a VIA definition for the TFG
  Magnetox XF, and a converter for Hansung's definitions.

The layout built on the XF is [us-ansi-104-key-to-jis](../layouts/us-ansi-104-key-to-jis/README.md).
